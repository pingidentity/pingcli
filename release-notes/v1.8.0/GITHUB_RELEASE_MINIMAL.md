### FEATURES

- PingFederate: Added `advanced-services pingfederate` commands for managing PingFederate deployed as a private tenant in PingOne Advanced Services, with client credentials, authorization code, and device code OAuth authentication

### ENHANCEMENTS

- PingFederate: Added `--id` as a settable create-body flag for PingFederate resources that accept caller-supplied instance IDs

### DEPRECATIONS

- PingOne: The `pingone languages agreement-revisions` command is deprecated and will be removed in a future release; use `pingone agreements languages revisions` instead
